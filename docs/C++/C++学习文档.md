# 建议学习路径

1. **语法打底**：第一章 → 第二章
2. **面向对象主线**：第三章 → 第四章 → 第五章
3. **工程能力**：第六章（编译链接、宏、内联）
4. **STL 与常用套路**：第七章（含仿函数与 Lambda）→ 第八章
5. **并发进阶**：第九章，配合附录速查运算符优先级
