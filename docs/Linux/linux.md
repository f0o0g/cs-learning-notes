# Linux 知识库

> 这既是本库的入口文档，也是全库总目录：前半部分是引言与用法，后半部分是按「篇 → 章 → 节」展开的完整目录。

## 引言

这套文档最初来自两批互不相干的笔记：一批从「命令怎么用」写起——命令行、Vim、GCC/GDB/Make、文件 I/O 与文件系统、内存管理；另一批从「程序怎么写」写起——正则、Git、进程与线程，最后落到网络服务器。整理时按「先会用、再会写、最后会做服务」的顺序把它们串成 01–09 一条线。

放在一起记的收益是可以前后对照：01 里 `ls -l` 看到的权限位，到 03 讲文件系统时会落到 inode 的 `mode` 字段上；02 的 `make` 自动推导，在 08 写多进程工程时会再用一次；08 的 `fork` 与 `exec`，在 09 写多进程服务器时就是 `accept` 之后的两个动作。所以这套文档既能顺序读，也能当查证材料：概念对不上时，先在本篇找定义，再顺着目录跳到相邻篇看实现。

各篇的组织方式统一：YAML front matter 记录篇名，正文一级标题是「第 N 章」，二级是「N.M」小节；示例代码可直接运行，命令前的 `$` 或 `#` 是提示符而非输入内容；插图集中在 `images/`，正文就近引用。

本文件只负责「从哪进、看什么」。

## 怎么用

- **顺序读**：01 → 02 → 03 → 04 → 05，打牢命令与系统编程基础；再 06 → 07 → 08 → 09 进入进阶主线。
- **按需查**：用下面的完整目录直达章节；查函数原型时优先看该章「附录」类小节（08、09 各有一份函数与命令速查）。
- **动手验证**：每篇的关键结论都配有可直接编译运行的示例，建议在个人目录（如 `~/linux-command-lab/`）中复现，不要在 `/`、`/etc`、`/usr` 下练习删除与覆盖。
