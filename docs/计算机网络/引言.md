# 引言

> 这份知识库要解决的问题很简单：把「协议是怎么规定的」和「代码怎么写、报文实际怎么走」放进同一套概念里。
> 阅读入口：[目录](<目录.md>)

---

## 一、知识库定位

这套笔记分两条线，共用同一套名词与图示，避免「背完八股却写不出代码」：

| 线路 | 主文档 | 回答的问题 | 适用场景 |
| --- | --- | --- | --- |
| 复习线 | 六个章节文档（[第一章](<第一章 概论.md>) → [第六章](<第六章 应用层.md>)） | 协议规定了什么、机制为何这样设计、考试怎么考 | 课程复习、考前突击、概念查漏 |
| 实践线 | [计算机网络.md](<计算机网络.md>) | Winsock 怎么调用、抓包里看到的是什么、坑在哪 | 写 UDP/TCP 程序、排障、性能调优 |

推荐顺序是：**先建立分层框架，再逐层深入，最后用代码与抓包验证**。

## 二、内容构成

1. **六章主线**：按五层体系结构组织，章名即文件名（`第X章 标题.md`），正文从 `# 一、…` 小节开始；章节内正文、图示、顺序与原始合稿完全一致，图片统一用仓库内 `assets/` 相对路径。
2. **专题笔记**：`计算机网络.md`，Socket 编程与协议实践记录，含代码、抓包结论与常见坑，独立成篇。
3. **归档合稿**：`历史版本/计算机网络（up：湖科大教书匠）-原稿.md`，未拆分的完整版（含 6 个章节标题），适合全文检索与导出。
4. **素材与图示**：522 张课程原图、14 张 AI 重绘白底图、三次握手/四次挥手矢量图，统一放在 `assets/` 与 `diagram/`。

## 三、阅读约定

- `**重点**`、`（重点）`：高频考点，复习时优先。
- `**补充**`、`（补充…）`：拓展内容，可先跳过。
- **图注即检索关键词**：如「TCP 三次握手图解」，全局搜「图解」就能定位机制图示。
- 公式统一用 `$$ … $$` 块，示例计算保留推导过程，便于复盘错题。
- 每章的一级标题就是章名（在文件名里），所以正文里出现的 `#` 标题都是**小节**级。

## 四、学习路径建议

### 阶段一：建立框架（1 ~ 2 天）

1. [第一章 概论](<第一章 概论.md>)：吃透三种交换方式的差异、时延/带宽积等指标口径。
2. 第一章「计算机网络体系结构」一节：弄清分层、协议、服务、实体四个概念，能画出封装与解封装全过程。

### 阶段二：逐层深入（2 ~ 3 周）

1. [第二章 物理层](<第二章 物理层.md>)：编码与调制、奈氏准则与香农公式的适用条件。
2. [第三章 数据链路层](<第三章 数据链路层.md>)：封装成帧、CRC 与可靠传输、CSMA/CD、交换机自学习、VLAN。
3. [第四章 网络层](<第四章 网络层.md>)：IPv4 地址与子网划分（必须手算）、路由选择协议、ICMP、NAT/VPN、IPv6。
4. [第五章 运输层](<第五章 运输层.md>)：TCP 三次握手/四次挥手、滑动窗口、流量控制、拥塞控制（含 Linux 调优实践）。
5. [第六章 应用层](<第六章 应用层.md>)：DHCP → DNS → HTTP 的完整解析链路。

### 阶段三：动手验证（1 周）

1. 读 [计算机网络.md](<计算机网络.md>) 的 UDP / TCP 两部分，跑通服务端与客户端。
2. 用 Wireshark 抓一次握手挥手与 DNS 查询，对照文中首部格式逐字段核对。
3. 复现文中提到的坑：粘包、`recvfrom` 阻塞、广播/组播配置、`SO_RCVBUF` 调优。
