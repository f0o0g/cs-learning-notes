# 计算机学习笔记

围绕 C/C++ 编程与计算机基础整理的中文学习笔记，涵盖语言基础、现代 C++、数据结构与算法、计算机网络、数据库、Linux（含 Git）和 Qt。仓库按八个主题收录 56 篇学习正文，便于系统学习、复习和查阅。

## 适合谁阅读

- 正在学习 C/C++，希望逐步建立计算机基础知识体系的学习者。
- 需要结合概念、图解和代码示例复习课程内容的读者。
- 希望按主题查阅知识点、易错点和面试问答的读者。

C语言文档从基础知识开始；数据结构、网络和 Qt 内容建议在掌握 C/C++ 基础后阅读。各文档中的代码块、命令与输出属于教学示例，运行环境以对应章节说明为准。

## 建议学习顺序

1. **语言基础**：C语言 → C++。
2. **语言进阶与算法**：现代 C++（11 → 14 → 17）、数据结构与算法。
3. **系统与应用基础**：Linux → 计算机网络 → 数据库。
4. **工具与界面开发**：Qt；Git 见 Linux 书系第 06 章，可从学习第一阶段开始配合练习。

第一次阅读时按章节建立主线，复习时使用下方文档导航。网络部分可结合湖科大课程笔记学习。

## 阅读与插图

正文采用 Markdown，全部插图均已保存到仓库。克隆或下载完整仓库后，可在本地阅读正文和查看图片。

- 在 GitHub 中打开 Markdown 即可阅读，也可克隆或下载后使用支持 Markdown 的编辑器查看。
- 各学科插图位于相应文档目录下的图片文件夹（通常为 `assets/`，Linux 进程编程为 `images/`）；湖科大网络课程插图集中存放于 `docs/计算机网络/assets/湖科大计算机网络/`，按序号和图意或章节主题命名。
- 下载或移动文档时，请同时保留对应的图片目录及相对路径；仅下载单篇 Markdown 不包含配套图片。
- 少量图示使用 Mermaid，数学表达式使用 LaTeX 语法；本地阅读器需支持相应渲染。
- 在线图片本地化后，原始 URL 保留在对应 Markdown 的 `image-source` 注释中，便于追溯。
