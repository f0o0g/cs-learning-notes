# 计算机学习笔记

围绕 C/C++ 编程与计算机基础整理的中文学习笔记，涵盖语言基础、现代 C++、数据结构与算法、计算机网络、数据库、Linux、Qt 和 Git。仓库按九个主题收录 15 篇学习正文，便于系统学习、复习和查阅。

## 适合谁阅读

- 正在学习 C/C++，希望逐步建立计算机基础知识体系的学习者。
- 需要结合概念、图解和代码示例复习课程内容的读者。
- 希望按主题查阅知识点、易错点和面试问答的读者。

C语言文档从基础知识开始；数据结构、网络和 Qt 内容建议在掌握 C/C++ 基础后阅读。各文档中的代码块、命令与输出属于教学示例，运行环境以对应章节说明为准。

## 建议学习顺序

1. **语言基础**：C语言 → C++。
2. **语言进阶与算法**：现代 C++（11 → 14 → 17）、数据结构与算法。
3. **系统与应用基础**：Linux → 计算机网络 → 数据库。
4. **工具与界面开发**：Qt；Git 可从学习第一阶段开始配合练习。

第一次阅读时按章节建立主线，复习时使用下方文档导航。Linux 问答可作为系统编程手册的补充阅读；网络部分可结合湖科大课程笔记学习。
